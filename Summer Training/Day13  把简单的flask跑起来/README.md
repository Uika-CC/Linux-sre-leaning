今天是7月28日，昨天部署完mysql和flask，今天就先跑个简单的web，两个脚本一个flask一个巡检脚本我也会一起放在这个文件夹，因为不需要频繁改动我就不用git了

首先要知道的是，现在的Linux一般都会配用一个ufw的防火墙， 我自己的Ubuntu默认是没开的，为了找茬我就开了

开之前记得把22端口开了，不然你ssh会断开
对应命令：sudo ufw allow 22/tcp

开了之后就可以把ufw防火墙打开了，我自己的flask用的是8005端口，把8005端口放行了之后，python web.py就可以了，但是开了flask之后会占用你一个xshell窗口，所以需要重新开一个

新开了窗口之后，可以先用ss -tnlp | grep 8005查看一下8005端口是否有在监听，一切都准备好之后就可以访问了：http://192.168.227.133:8005/

遇到的坑：你把flask脚本改了之后，要重新启动脚本，不然结果不会变
