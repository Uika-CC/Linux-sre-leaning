先梳理一下常见的HTTP状态码

2xx   成功
200：请求成功
201：创建成功
204：成功但是无返回内容

3xx   重定向
301，302：网页跳转

4xx   客户端错误
400：请求错误
401：未认证
403：没权限
404：网页不存在

5xx   服务端错误
500：程序报错
502：网关错误
503：服务不可用
504：网关超时
