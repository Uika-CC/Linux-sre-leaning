今天的内容：

首先是命令方面

free -h：查看内存
输出解释：total，总内存，used，已经使用的内存，free，完全空闲的内存，buff/cache，缓存，available，可以分给程序的内存

top -o %MEM：按内存排序
输出看三个东西：
1.哪个进程的%MEM最高
2.RES（实际占用的物理内存）是不是一直在涨
3.如果VIRT很大但是RES很小，说明有虚拟内存但是没有真正使用

vmstat 1（每秒刷新）
重点看两列：
si：从swap换入内存
so：从内存换出到swap
如果这俩都长期为零的话，就是系统在用硬盘当内存，一定会内存紧张

解释一下swap：当RAM（物理内存）不够用的时候，Linux会把一部分不常用的数据从内存搬到硬盘上的swap分区，腾出物理内存分给其他的程序使用
